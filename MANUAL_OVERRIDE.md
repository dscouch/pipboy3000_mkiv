      MANUAL OVERRIDE
      Operational Instructions

      Follow these rules in the order they are listed.
      Perform the first action that applies.

      If instructed to HOLD the button, refer to
      "Releasing a Held Button."

      PRESS OR HOLD RULES

      1. If both indicators are lit and the button is WHITE:
         PRESS immediately.

      2. If the button color is BLUE:
         PRESS only when the countdown timer shows 3.

      3. If the button says "ABORT" and exactly one indicator is lit:
         PRESS.
         Otherwise HOLD.

      4. If the button color is BLACK:
         HOLD.

      5. If the button says "DETONATE" and the button is BLUE:
         PRESS.

      6. If the button color is RED and CAR is lit:
         PRESS.
         Otherwise HOLD.

      7. If the button color is GREEN and exactly one indicator is lit:
         HOLD.

      RELEASING A HELD BUTTON

      If you are instructed to HOLD the button, observe the strip color
      and release the button only when the countdown timer shows the
      correct value.

      Black strip: release when the timer shows 3
      White strip: release when the timer shows 7
      Yellow strip: release when the timer shows 6
      Any other color strip: release when the timer shows 8
